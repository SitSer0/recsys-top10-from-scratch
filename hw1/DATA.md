# Данные

**Ситников Серафим Владимирович**

Датасет: **Amazon Reviews 2018, Digital Music, 5-core**.

- Первоисточник: https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/
- Авторы: Jianmo Ni, Jiacheng Li, Julian McAuley (UCSD).
- Публикация: https://aclanthology.org/D19-1018/
- Отзывы: https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/categoryFilesSmall/Digital_Music_5.json.gz
- Метаданные: https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/metaFiles2/meta_Digital_Music.json.gz

Скачивание реализовано в `data_utils.download()`, вызывается из `experiments.ipynb`.
SHA-256 обоих файлов зафиксированы в `data_checksums.json`.
Кеш по умолчанию: `hw1/.cache/amazon`; альтернативный путь задаётся `RECSYS_DATA`.
Данные и кеш в Git не добавляются. Соблюдайте условия доступа, опубликованные источником;
лицензия кода репозитория не распространяется на данные.

В исходной 5-core выборке 169 781 отзыв, 16 566 пользователей, 11 797 объектов.
После удаления повторов user–item с сохранением первого события: 145 292 отзыва,
16 566 пользователей, 11 797 объектов. Используется вся очищенная выборка.
Повторное выделение k-core и случайный отбор не выполняются.

Сигнал: оценка отзыва 1–5, положительная релевантность — оценка ≥4.
Timestamp — время отзыва с дневной точностью. Метаданные — формат товара из
отзыва и недатированный snapshot названий/категорий/брендов. Последний используется
только для EDA и подписей; FM использует метапризнаки обучающей истории и формат,
наблюдавшийся до cutoff. Подробности и ограничения в основном ноутбуке.
