# Персональные top-10 рекомендации: пять моделей с нуля

**Ситников Серафим Владимирович**

Учебный эксперимент на Amazon Reviews 2018 / Digital Music: ItemKNN, iALS,
EASE, FM с метапризнаками и ALS с собственным таргетом оценки и давности.
Все реализации обучения, скоринга, top-10 и метрик написаны в этом репозитории.

Основной материал: [hw1/experiments.ipynb](hw1/experiments.ipynb) — выполненный
ноутбук с EDA, формулами, временным протоколом, подбором на validation,
графиками, финальным сравнением и выводами.

## Запуск

Python 3.11, CPU. Первый запуск скачивает открытые данные с первоисточника.
Нужны несколько ГБ свободной RAM для EASE; данные занимают около 31 МБ в gzip.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r hw1/requirements.txt
cd hw1
python checks.py
python run_notebook.py
```

Кеш: `hw1/.cache/amazon`, либо путь из `RECSYS_DATA`. Проверяются SHA-256 файлов.
Версии прямых зависимостей закреплены в `requirements.txt`, полное исходное
окружение — `requirements-lock.txt`. Notebook можно выполнить через Jupyter
в этом же окружении. Seed=42, CPU, 2 потока; другой BLAS может давать небольшие
численные отличия. Данные, веса моделей и окружение не коммитятся.

## Протокол

После очистки: 145 292 взаимодействия, 16 566 пользователей и 11 797 объектов.
Глобальные границы UTC: 2016-06-16 и 2017-02-01. Каталог определён только train.
Все методы используют одинаковые полные наборы кандидатов, маску истории и
релевантность rating ≥4. Основная метрика до подбора — macro NDCG@10;
дополнительные — Recall@10 и покрытие каталога. Новые ID исключаются из
warm-start сравнения, потери явно отражены в ноутбуке.

FM использует известные к cutoff метапризнаки истории и формат товара из
первого обучающего отзыва. CustomALS меняет сам таргет (знак/силу оценки и
давность), сохраняя confidence и параметры выбранного iALS. Дополнительно
выполняется ID-only абляция FM и paired bootstrap разностей NDCG по пользователям.

## Результаты

| Модель | NDCG@10 | Recall@10 | Coverage@10 |
|---|---:|---:|---:|
| ItemKNN | 0.01493 | 0.02442 | 0.62036 |
| iALS | 0.01610 | 0.02533 | 0.08828 |
| EASE | 0.01941 | 0.02929 | 0.41685 |
| FM | 0.00792 | 0.01137 | 0.04522 |
| CustomALS | 0.01787 | 0.02767 | 0.08776 |
| FM_ID_only | 0.01259 | 0.02032 | 0.02024 |

Test: 2 233 пользователя, полный train-каталог из 11 611 объектов. EASE — лучший по NDCG@10 и Recall@10 в этом запуске. CustomALS улучшил точечную оценку iALS, но paired 95% интервал разности включает ноль. Выбранные метапризнаки FM ухудшили NDCG относительно ID-only абляции; вывод ограничен выбранными признаками и настройками.

## Файлы

- `hw1/DATA.md` — автор, источник и получение данных.
- `hw1/models/` — пять самостоятельных реализаций.
- `hw1/data_utils.py` — загрузка, очистка, разбиение, train-only признаки.
- `hw1/evaluation.py` — полный каталог, маскирование, top-10, метрики.
- `hw1/experiment.py` — сетки поиска и финальный эксперимент.
- `hw1/checks.py` — независимые численные проверки и проверки протокола.
- `hw1/results/` — агрегированные результаты, конфигурации и кодированные примеры.

Датасет: [Amazon Reviews 2018, UCSD](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/).
Исходные данные не распространяются в этом репозитории.
